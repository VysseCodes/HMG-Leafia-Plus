STEP 1

Run the Leafia kit

Needs NEMESIS on the head unit. The kit only reads; nothing on the car changes.

  1. Unzip the kit to the root of an exFAT or FAT32 USB drive.
  2. With the car on, plug in the drive and tap Yes when NEMESIS asks to run it.
  3. When it reports success (1–2 minutes), take LEAFIA/public/LEAFIA-REPORT.txt from the drive.
Download the Leafia kit

One kit for everything. Its LEAFIA/public folder (this report, plus a problem summary) is safe to share: firmware IDs, checksums and patch-spot checks, no VIN, serial numbers, phone or Wi-Fi names, accounts, keys or Kia/Hyundai code. LEAFIA/private holds logs, stock system files and key files for porting and debugging: never post it; send it privately only if a maintainer asks.

Help add your car

Gen5W cars we have no full build for yet (US and Canada). On any of them the package already installs wireless Android Auto (basic mode). Turn-by-turn and wireless CarPlay need one owner's files: run the Leafia kit above and share your report, and we may ask you privately for its private folder. Cars marked Priority help the most people.

Only the model years listed are Gen5W; where a year also had an older head unit, the row says which versions are Gen5W. Newer refreshes of several of these models (for example the 2024+ Kona, Santa Fe and Sonata, and the 2025+ Tucson, Sportage, Palisade, Carnival, Ioniq 5 and EV6) use ccNC, a different head unit that NEMESIS doesn't support, so they can't run this package.
